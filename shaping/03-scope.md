# MVP 范围

> 说明：DSL 已内置"面试官+HRBP"人设与"批判-解析-建议"方法论视为"已具备"；本表按"面向招聘方"方向调整流程封装层。

## 做

- 简历文件上传与文本提取（JPG/PNG/PDF 等，文档提取器）【DSL 已具备】
- 可选粘贴目标岗位 JD（sys.query 输入）【DSL 已具备】
- 面向招聘方的简历评估流程【需在 DSL 5 步基础上适配，见 Q8】：
  - Step1 第一印象定论 → 「约面/不约面」初判 + 一句话理由
  - Step2 地毯式深度审计 → 硬伤/夸大/术语误用/逻辑矛盾识别
  - Step5 最终裁决 → 整体评价 + 核心风险点 + 约面/待定 + 追问清单
- "批判-解析-建议"三位一体、分级批判、"所以呢？"拷问、JD 匹配、忠于原文【DSL 已内置方法论】
- **账号登录 + 多会话历史记录**
- **分步卡片式结果展示（结构化前端）**
- **结果导出 PDF**（合并为一份完整评估报告）

## 暂缓

- 批量多份简历一键评估
- 简历评分/排名、与岗位的自动匹配度打分
- 接入真实招聘数据做岗位画像反查
- 对外商业化（定价、支付、权益体系）

## 不做

- 帮候选人改写简历/输出范本重构（Step4，与"面向招聘方"方向冲突）
- 自动编造候选人信息或能力（违背"忠于原文"）
- 直接对接招聘平台自动约面/发通知
- 简历美工/排版设计（聚焦内容而非格式）
